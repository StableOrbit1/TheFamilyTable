How to Initialize Firebase AI Logic

Project: anon-5693a Tap "Test AI Connection" to verify your Firebase AI Logic setup. 

      


      
      

        

          1. Enable in Firebase Console (Required Once)
        

        
    
          
  1. Open the Firebase Console and select your project (anon-5693a).
    2. 
          
  2. In the left sidebar, go to Build → AI Logic (or Firebase AI Logic) and click Get started.
    3. 
          
  3. Choose Gemini Developer API and click Enable (this turns on the required Google AI / Vertex AI APIs for your API key).
    4. 
          
  4. Also ensure Build → Firestore Database and Build → Authentication → Anonymous are enabled so recipes save across reloads.
    5. 
          
  5. CRITICAL FOR GITHUB / LOCAL TEST: Open your browser's Developer Tools Console (F12). Find the printed AppCheck debug token: xxxx.... Copy it, go to App Check → Apps in the Firebase Console, click the 3 dots next to your app, and select "Manage debug tokens" to paste it!
    6. 
        

      


      
      

        

          2. Initialization Code (Already Active in This App)
        

        
import { initializeApp } from "https://www.gstatic.com/firebasejs/12.6.0/firebase-app.js";
import {
  getAI,
  getGenerativeModel,
  GoogleAIBackend,
  Schema
} from "https://www.gstatic.com/firebasejs/12.6.0/firebase-ai.js";
